rclone-backup

rclone-backup is a personal, single-user OAuth client for rclone. Its owner uses it to store end-to-end encrypted backups (made with restic) in his own Google Drive.

It is not a public service. No one else uses it, and it has no sign-up.

It requests only the Google Drive drive.file scope, so it can see and manage only the files it created itself, not the rest of the Drive.
